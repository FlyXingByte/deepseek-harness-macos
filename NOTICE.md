# Notice

This is an independent, unofficial macOS launcher for DeepSeek Harness. It is not affiliated with, endorsed by, sponsored by, or maintained by DeepSeek. “DeepSeek” and “DeepSeek Harness” are referenced only to identify compatibility. The launcher icon is original and is not the official DeepSeek logo.

The launcher does not bundle DeepSeek Harness, Node.js, user credentials, sessions, workspaces, or logs. With the user's confirmation, v3.0.0 invokes npx to obtain the default recommended official package @deepseek-ai/dsh@0.1.2-alpha.3. The last verified fallback is @deepseek-ai/dsh@0.1.1-rc.2, and version history is retained down to 0.1.0-rc.6. The default update channel follows npm latest/next; following later alpha releases requires an explicit channel opt-in.
