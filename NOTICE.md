# Notice

This is an independent, unofficial macOS launcher for DeepSeek Harness. It is not affiliated with, endorsed by, sponsored by, or maintained by DeepSeek. “DeepSeek” and “DeepSeek Harness” are referenced only to identify compatibility. The launcher icon is original and is not the official DeepSeek logo.

The launcher does not bundle DeepSeek Harness, Node.js, user credentials, sessions, workspaces, or logs. With the user's confirmation, it invokes npx to obtain the bundled-default official package @deepseek-ai/dsh@0.1.0-rc.6 or a newer version explicitly selected through the launcher's official npm update check. The verified bundled version remains available as a rollback option.
